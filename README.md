## 🌍 Sobre o NASA Space Apps Challenge  

O **NASA Space Apps Challenge** é uma hackathon global que reúne equipes do mundo todo para criar soluções inovadoras para desafios ligados ao espaço e à ciência.  

Em 2024, nosso time explorou como seria observar o céu noturno a partir de **outros mundos**, utilizando dados de mais de **5500 exoplanetas** do Arquivo de Exoplanetas da NASA.
